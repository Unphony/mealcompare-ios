# 0.3.0：电脑后端与手机连接验证

本次实现方案 A 第一阶段：Windows 客户端、电脑后台、任务与记录、手机通信和人工接管。完整配餐调度尚未迁移；稳定读取的金额标为候选，不进入正式前沿。旧手机验证工具可从新首页打开。

## 使用步骤

1. Windows 保留 Microsoft Edge，打开解压后的 `饭价电脑端/启动饭价.cmd`。目录内其他文件须保留，不能只复制 exe。
2. 电脑与 iPhone 安装 [Tailscale](https://tailscale.com/download)，使用同一 Personal 免费账号登录，手机开启 Tailscale VPN。
3. 电脑端点击“启用手机连接”。如首次需要 HTTPS 授权，在 Tailscale 完成后重试。饭价使用私人 HTTPS `8443` 端口，不开启 Funnel，不覆盖已有 `443` 服务。
4. 用此前免费自签方式安装 0.3.0 IPA，覆盖原饭价。填入电脑显示的完整 HTTPS 地址与八位配对码。配对码十分钟有效且只可用一次。
5. 手机选择平台，打开“接管电脑网页”，在专用会话中登录、选择地址及餐品。原来手机网页的会话不会自动迁移到电脑。
6. 结束接管，再检测当前结算页。先在同 Wi-Fi 测试，再关闭 Wi-Fi 用手机流量测试。

## 当前行为

- 关闭窗口留在托盘；可选 Windows 登录后启动。运行时阻止自动休眠，显式关机或休眠仍会断线。
- 手机配对密钥在 Keychain，电脑仅保存哈希。可在电脑撤销所有配对。
- 手机发起搜索、检测、已适配的历史摘要读取；任务编号去重，WebSocket 更新进度。手机进入后台不重复创建任务。
- 接管前排空当前动作并暂停查询。点击、拖动、滚动、输入作用于同一网页；结束后重新检测，不重放旧操作。
- 每次输入消耗画面编号，十秒后需要刷新；截图不保存，输入文本不进入记录。用户手动处理验证码，平台拒绝时保持暂停。
- SQLite 保存任务、候选金额和常买摘要。重启中断任务标为中断。手机离线显示带时间的旧记录。
- 比较核心和旧手机工具均改为“同价更多、包含且不更贵”；送达时间不参与支配，未知套餐不推定拆分。

## 验收边界

自动选规格、已有券遍历、凑单试价的电脑调度尚未完成。真实家庭网络与手机流量、验证码、锁屏后页面行为、电脑网页优惠与独立淘宝闪购 App 一致性仍需真机测试。模拟页面与本地接口测试不代表完整比价成功。

后续按照已批准顺序：先通过通信与接管验收，再移植单店调度，补齐结算时购物篮、门店和地址证据，以汉堡王和牛约堡 30 元用例验证，之后扩展历史候选与自动入店。

## 开发

使用 Node.js 24 LTS，在 `Desktop` 下依次执行 `npm ci`、`npm test`、`npm start`。`npm run package` 生成本地免安装目录，附带 Electron，最终用户无需 Node.js。使用系统 Edge，初次下载 Electron 二进制需联网。

`node scripts/smoke.mjs` 使用独立目录启动隐藏测试窗口，检查真实 Electron、SQLite 和配对接口，保存本地测试截图。临时资料、产物与登录状态不提交 Git。

网络依据：[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)。桌面隔离依据：[Electron 安全指引](https://www.electronjs.org/docs/latest/tutorial/security)。
